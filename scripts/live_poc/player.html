What this is

  • Live from the AGX at the venue: Zowietek HEVC 3840×2160 → hardware decode, scale and H.264 encode on the Jetson → HLS → S3 → CloudFront → this page.
  • Each segment carries EXT-X-PROGRAM-DATE-TIME. The wall-clock under each player is read from the playing fragment's PDT — that value is the anchor the whole timestamp rebase depends on.
  • It is an EVENT playlist, so the scrub bar reaches back to the moment the publisher started. That is the DVR the annotator gets, with no buffer window to manage.
  • The court is empty — no games for two weeks. The point is the pipeline, not the basketball.
